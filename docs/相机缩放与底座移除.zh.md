# 相机缩放与底座移除

移除早期原型独立 ChairBase 底座、台面网格及其绘制。用户半身模型直接显示；旧测试头型的占位肩部归入角色，随角色整体转动。

主场景与表情页支持鼠标滚轮、模型区域内双指缩放，以及小尺寸拉远、复位、拉近按钮。相机距离限制为默认的 0.55～1.65 倍；仅移动相机，不缩放模型，不重建发型，不改变物理尺寸。表情页两种方案同步缩放，拉近时取景向脸部移动。

第二指进入后取消当前剪发、梳理、吹风或旋转手势，直到所有手指离开才允许下一次单指操作。第二指进入前已发生的操作不撤销。失焦和后台切换清理触点状态；鼠标滚轮和按钮同样中断当前操作，防止把相机移动误当作剪刀划线。

独立预览渲染、屏幕投影、射线、视线跟随与旋转区域使用同一个实时相机距离；Cocos 使用 Camera 自带投影和拾取。缩放控件只改变镜头，不重载模型、材质或表情，也不改变当前造型。

当前为单人离线原型，不涉及联机同步。浏览器可验证鼠标和按钮效果，自动测试验证双指接管、范围、取消与缩放后的发梢命中。Cocos 类型检查不代替 Creator 与微信真机多点触控验收。
