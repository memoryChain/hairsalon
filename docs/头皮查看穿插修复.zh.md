# 头皮查看穿插修复

## 原因

绿色头皮覆盖域的拓扑没有缺面，但原显示只把 608 个粗三角形的顶点沿法线抬高 0.012。顶点贴合不能保证整个三角形在头模外，跨过太阳穴和侧后脑曲率变化时，面内会被可见头模遮住。旧用户头型的面内采样发现 8 个粗面发生穿插，最深约 0.00276 个场景单位。

## 修改

新增 ScalpDisplayMesh，仅用于查看头皮。共享边细分两轮，每个原三角形分为 16 面；按原父面保留诊断配色。以实际可见半身网格建立 BVH，从头部中心进行径向检测，仅向外修正局部内陷，不把耳后连续跨接拉进凹面。另检查边和三角形内部的净空，通过共享顶点一起修正，避免独立补片带来裂缝。用户头型显示为 9728 三角形。

首次查看时构建并缓存，头皮资产变化才重建；旋转仅更新缓存位置，普通理发模式不构建此网格。法线与面内微小间距用于防止遮挡争夺；未关闭深度测试，也未放置始终存在的覆盖帽。

真实发根、发缕数量、剪切网格与物理求解保持原有数据。这是查看覆盖域的显示贴合修复，不声称解决全部头发梳理与头模碰撞问题。

## 验证

自动测试在三种头型的每个细分面上使用与修正算法不同且更密的采样网格，验证顶点、边及面内均位于可见头模外；验证欧拉特征与共享边连续，输入资产不变，整体旋转正确，缓存复用，切换头型时更新，退出查看且完全剃光后不残留覆盖层。
