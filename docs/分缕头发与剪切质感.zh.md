# 完整发根与分缕剪切

日期：2026-09-19。高密实验已撤回，恢复本文的原始分缕密度；当前投影斜切入口保留。本版用于解决整块发体、整片封口和成块下落带来的“切豆腐”观感。

## 当前结果

- 原头皮仍为标准 608 面 / 非标准 756 面，没有通过加密头皮掩盖问题。
- 相邻头皮三角形配成不重叠的小区，每个原始面恰好归属一个小区，根部面积总和与输入头皮完全相等。标准头型 304 个小区，非标准 378 个小区。
- 每个小区生成一条独立卡通发缕。底面使用原始头皮三角形，根顶点精确绑定；上层沿曲线逐渐收窄和分开。头皮覆盖来自根域划分，不依赖发簇互相遮缝，也没有另加不可剪发帽。
- 每缕四个截面环，分别位于曲线参数 0、0.20、0.62、1。初始三角形分别为 8512 / 10584。标准 321 个、非标准 397 个物理导向点数量不变，没有为每缕创建节点或刚体。
- 尖刺按主要方向汇成几个大尖，内部由细缕组成；长发采用沿头型外侧垂落的曲线，前额中部保留短刘海。截面按相邻曲线切线逐段运输，避免翻转和宽片拉伸。
- 当前剪刀改为即时投影滑动剪发，命中当前三角形后按滑动小段的相机平面裁剪，保留原粗细、独立小封口和碎发。操作与算法见 [投影滑动剪发](投影滑动剪发.zh.md)。不显示刀线，但复用真实平面裁剪核心。
- 碎发在同一绘制批次中保存发缕编号。落刀瞬间继承位置和速度，随后短时、按缕施加不同方向的小散开力；同一缕内部所有顶点受相同力，不撕开三角面。

## 数据结构

| 模块 | 职责 |
| --- | --- |
| FiberLayout | 面域配对、原始根面归属、生成独立封闭发缕和组编号 |
| FiberRig | 局部造型曲线、截面运输、根部刚性绑定、世界空间惯性位移 |
| BoundHairMesh | 原始截面采样点与切割交点的持久混合绑定 |
| StrokePlaneCutter | 当前三角形与滑动平面相交、有限段拾取、局部根部保护与遮挡 |
| HairMeshGroups | 提取命中发缕，将裁剪结果合回当前网格 |
| PlaneHairCutter | 局部发缕真实平面裁剪、双侧封口、闭合与预算检查 |
| FiberDebris | 整缕碎发打包、按缕预算、省略过量显示碎片、短时散开力 |
| SurfaceHairGeometry | 根域调试显示、发缕色差、低对比切口、合并网格 |

发缕视觉采样与物理导向解耦。FiberRig 每帧复用位置数组；裁剪交点仅保存已有采样点的混合权重，因此不会在下帧重新长回去。发根在完整覆盖域中始终绑定到输入网格。上层可以造型交叠，这是发型层次，不是覆盖头皮的补洞手段。

每条发缕独立封闭，所以相邻根域的边会在同一位置接触。验证必须按发缕检查索引边和绕序，不能把所有共位置顶点重新焊成一整块再要求每边只有两个面。根域覆盖另外验证：原面唯一归属、面积相等、根顶点贴合误差小于 1e-10。

## 操作与原型边界

默认滑动剪发；旋转移至头部下方区域，上下各 30° 俯仰以及剃刀保留。可以选长发，直接划过发梢观察即时断口和碎发下落；尖刺剪完后从下方拖动俯视，能看到分开的截面。

剃刀仍编辑有限分辨率导向长度，各小区按相邻导向的平均保留长度收缩。边缘会有过渡，不是逐根毛发的精确剃刀。全部长度归零后，所有发缕和切面不再输出；恢复会清空剪切与碎发。

这是数百条卡通发缕的几何原型，不是写实单发系统。尚未实现发缕之间的自碰撞、完整头肩碰撞、精细发丝材质或艺术家梳理导向。剧烈转动、极端头型或连续深剪仍可能出现局部穿插。刀线穿过头皮、任意内部挖削、无限次数的布尔修剪不在当前支持范围。

## 性能与预算

- 附着发体：最多 54000 个三角形角点（18000 面）、14000 个混合绑定顶点。
- 碎发：最多 12 批、16000 个角点、5 秒回收。超量时按整缕省略显示，不能截断半条缕。源发型的剪切仍完整执行；切割结果保留被显示预算省略部分的体积审计值。
- 合并动态网格容量 72000 个角点，三维依旧为头部、静态围布/底座、头发/碎发三个网格。没有新增纹理或每缕绘制调用。
- 可见性按根小区计算一次，避免每个三角形重复遍历导向。拓扑分配只发生在重置和剪切事件；普通帧复用数组。
- 以下是切换即时投影操作之前的历史测量；当前输入事件测量见投影滑动剪发文档。本机 Node 热身后测试长发的模拟加几何生成：标准中位 1.46 ms、P95 2.78 ms；非标准中位 1.65 ms、P95 3.33 ms。一次大范围剪切约 50–55 ms，说明剪切事件仍存在卡顿风险。这不含 GPU 上传/绘制，也不是手机性能结论；微信端需测峰值，必要时再把裁剪分帧执行。
