# 连续头皮覆盖原型

日期：2026-09-19。当前运行入口已切到本方案；当前根域已改为互不重叠的 304 / 378 个小区，外层独立分缕，见 [分缕头发与剪切质感](分缕头发与剪切质感.zh.md)。旧独立发簇代码保留作历史对照与回归，不再负责当前画面的头发。已接入背景手势旋转、上下各 30° 俯仰和发梢平面斜切，详见 [操作与斜切实现](操作与斜切实现.zh.md)。

## 这次验证什么

给定一片有效头皮三角网格，每个面只出现一次，每个顶点只有一份位置和长度。相邻面共享边与顶点，根域完整覆盖来自输入网格的拓扑，不通过独立发簇重叠遮缝。

当前将完整头皮面域分配给独立发缕，各根底面使用原始三角形，既不遗漏也不重复。根部相接，上层逐渐分开；每条发缕独立封闭。全部导向长度归零后，头发网格顶点数为零，没有额外保留的发帽。早期整块连续发体仅作为技术演进记录，不再用于正常渲染。

## Blender 测试模型

- 源文件：`sceneresource/TestScalps.blend`。
- 生成脚本：`scripts/build-test-scalps.py`。独立后台 Blender 创建新场景，不访问用户正在编辑的窗口文件。
- 标准头型：321 个头皮顶点、608 个三角形、32 条发际线边。
- 非标准头型：397 个头皮顶点、756 个三角形、36 条发际线边；左右不对称、高宽和后脑形状不同，网格数量也不同。
- 头皮直接从各自头模面域提取，绑定位置逐顶点一致；校验记录为 `sceneresource/test-scalps-audit.json`。
- 运行时使用 `assets/resources/scalp/test-heads.json`，同时包含两个实际头网格、头皮网格、法线与对应索引。独立预览在构建时复制同一份数据，Cocos 通过 ResourcePaths 加载原资源。没有另用解析椭球替代导入头皮。
- 六向离线检查图在 sceneresource，属于验证预览，不进入 assets。五官是运行时方向标识，按导出头模表面重新定位；不是 Blender 头模的一部分。

重新生成：

```powershell
python scripts/run-blender.py --blender "本机 Blender 可执行文件路径" -- --python scripts/build-test-scalps.py
```

配置 BLENDER_EXECUTABLE 后也可执行 `npm run models:generate`。源脚本无固定个人路径。Blender MCP 本次连接不可用，因此使用独立后台 Blender 5.1.2，未启动或截图 Creator。

## 数据和模块

| 模块 | 职责 |
| --- | --- |
| ScalpTopology | 验证面归属、共享边、法线、绑定、单片无孔洞区域，建立邻接与面积 |
| SurfaceHairSimulation | 共享长度场、两种造型场、世界空间惯性、根部绑定、修剪和掉落 |
| SurfaceHairGeometry | 从同一覆盖域生成封闭发体，剃光区域移除，不生成重复覆盖层 |
| SurfaceScreenCutter | 按根域定位的剃光笔，保留旧长度剪短供回归 |
| SalonGesture | 起点拾取与手势锁定，统一 Cocos 和 Web 输入语义 |
| BoundHairMesh / PlaneHairCutter | 裁剪持久网格、交点绑定、双侧封口和碎片 |
| HeadPose | 头部旋转、俯仰与射线逆变换 |
| HeadRaycast | 基于真实头网格的 BVH 遮挡，阻挡透过脸剪后脑 |
| HairSalonApp / SalonRenderer | 加载资源、头型切换、共用材质和动态网格 |

头发根部按输入头皮绑定；外表面采用每顶点弹簧惯性和邻接位移平滑。每个表面顶点只计算一次，移动时相邻面仍使用相同顶点。根到外表面的位移渐进衰减，因此根部不随末端自由摆动。基础步长 1/60 秒，每帧最多 4 步。

剪短保留截断点的当前位置和上一位置；掉落部分由旧表面与新表面形成封闭薄体，各顶点继承原速度后受重力和地面约束。当前掉落是面片薄体近似，不是独立刚体或完整软体。最多 12 个碎片批次，碎片总顶点不超过 16000，5 秒回收。普通更新复用数组，改拓扑只在修剪事件分配。

## 操作与语义

1. 标准头型 / 非标准头型：更换真实头网格及其头皮。切换会重置头发。
2. 尖刺 / 长垂发型：同一头皮覆盖域上的两种长度、方向造型场，切换会重置。
3. 默认斜切剪刀：按下命中头发后拉出刀线，松手按透视刀平面裁剪实际网格并封口；轻点不剪。刀线靠近或穿过头皮时拒绝。本版用于头皮外发梢，不是任意局部挖削。
4. 局部剃光：按下命中头发后，沿头皮位置涂抹，剃掉这个根域长出的头发；不是在离头皮很远的尖端涂抹。采用真实头模遮挡，后脑需要转过来。
5. 查看头皮：暂时只显示绿色头皮三角网格，不修改剪切状态，此时禁止剪切；再次点击恢复头发。
6. 恢复发型：清空剪短、剃光与碎片。普通工具切换和查看头皮不会重建角色或重置头发。

所有工具中，从头发以外按下并拖动都旋转头部；该次手势经过头发也不会误剪。上下俯仰各限 30°，横向转向不设范围，拖动角度即时响应；松手头部停转，发梢继续余摆。观察模式允许在任意位置拖动旋转。围布与底座保持稳定。

## 验证和预算

初始头发几何：标准头型 304 条发缕、8512 个三角形，非标准头型 378 条发缕、10584 个三角形，包含每缕根面、侧壁和末端。三维仍为角色、座椅和头发三个网格，共用材质；不是每个头皮面创建一个节点。

新增自动测试覆盖两套实际输入的完整面域、无重复面、根部绑定、封闭边、局部剃光、整头剃光归零、真正头模遮挡、速度继承、急转衰减、非法网格拒绝、连续剪短与碎片容量。独立预览已检查绿色头皮、局部剃光、头型切换、旋转和非标准头型长发剪短。

## 明确的边界

- 当前已实现卡通分缕，尖刺汇向几个主方向，长发沿头型垂落；仍不是最终角色美术，写实单发、精细材质和完整自碰撞尚未实现。
- 当前输入合同是从头部提取、单片连通、无孔洞且面朝向一致的头皮，附头顶点对应索引。非标准形状和顶点数量可以不同；与头模拓扑完全独立的头皮，需要增加离线投影及三角形重心绑定导入器，不能直接填错误的对应索引。
- 已检测非法索引、重复面、断开、孔洞、法线和贴合错误；没有做任意坏扫描模型的自动修复或完整自交检测。严重凹陷与复杂卷曲还需要离线修复、碰撞和防折叠约束。
- 根域无遗漏由面域唯一归属保证，不等于任意物理参数下都能保证几何无自交。当前形状保持、位移限幅和根部法线约束服务于两个测试头型。
- 剃光精度仍受头皮分辨率限制，边缘可能呈三角形或斜坡。斜切在三角形边内生成交点，不再只靠原导向顶点截短；支持范围和混合操作限制见新实现文档。
- Creator 类型检查与桌面测试不能证明微信性能、触摸坐标或 GPU 表现。尚未导出微信包、未做真机验收。
- 本轮完全单人离线，无网络同步或发布操作。
