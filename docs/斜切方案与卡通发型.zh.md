# 斜切方案与卡通发型

日期：2026-09-19。当前连续头皮原型已实现带头皮保护的发梢平面斜切，见 [操作与斜切实现](操作与斜切实现.zh.md)。下面保留最初独立发簇阶段的方案评估和造型记录，不代表当前运行结构。

## 斜切难度

对当前少量、封闭、分簇的头发，沿直线形成真实斜切口属于中等规模改造；若同时要求任意曲线、多次穿过弯曲发束、无限反复修剪及复杂碎片，则难度明显增加。主要成本在几何和变形绑定，不需要换引擎或接通用刚体系统。

当前代码只截断粒子链，并用垂直于中心线的截面封口。因此改一个法线或倾斜端盖并不等于真实斜切：侧面轮廓也必须被刀平面裁掉。

建议按以下步骤推进：

1. 连续输入先保留现有投影候选筛选。透视镜头下，由刀线两端的相机射线生成穿过相机的切割平面；限制屏幕划线的作用范围，防止无限平面误切远处头发。
2. 在实际变形后的发束网格上裁剪两侧三角形，生成交点与有序边界，分别封闭留在头上的部分和掉落部分。不能假设所有切口都可简单以中心点扇形填充。
3. 继续复用当前粒子链负责惯性与掉落；新增裁剪顶点需要保存链段权重和局部偏移。后续每帧从绑定重建变形后的顶点，不能再次用原始圆环生成器覆盖切面。
4. 再次剪切时裁剪已经截断的网格，限制新增顶点、碎片数和最小厚度。仅在剪切事件改变拓扑，平时只更新变形。

首版建议约束：一次直线手势、单簇单处截断、有限修剪次数；点击无刀线时保持现有普通剪切。刀线几乎平行发束、切到尖端或头皮附近时明确保留最小长度保护。多次穿过同一弯曲发束与局部削薄留到后续。

验收需覆盖正反斜切、多个相机角度、快速输入、头部遮挡、重复剪、近切线、同一闭合边界两侧一致、切口无裂缝、摆动后形状保留，以及微信真机事件耗时。

## 卡通发型本次改动

旧预设的 37 簇由经纬线均匀生成，长短和朝向相近，形成一圈放射状直锥。新预设在 HairPresets.ts 中明确编排 27 簇：

- 7 个主要大尖构成高低错落的轮廓；
- 额前独立刘海向下弯，左右不完全对称；
- 两侧向后梳，耳旁不横向伸出一整圈刺；
- 后脑使用较短的覆叠发束；所有层都可剪，不添加不可剪实心发帽；
- 中段宽度较饱满，末端集中收尖，采用接近黑色的冷色面。

每簇仍为 7 个控制点、6 边截面，尖刺初始 2268 个三角形，低于旧版 3108 个。物理、投影剪切和碎发回收沿用原实现。此版是运行时可剪造型试稿，仍有低面数折面、宽束穿插和局部覆盖近似；进一步精修宜制作独立导向曲线及宽厚截面数据，而不是直接把不可变形的整体头发模型覆盖上去。
