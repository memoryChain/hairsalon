# 秃顶发型扩展

2026-09-19：在原十款后新增第 11–15 款。

| 款式 | 生长区域与造型 |
| --- | --- |
| M 型后退 | 提高额中和两侧额角，顶部保留短发，向后梳 |
| 头顶圆秃 | 去除偏后头顶的椭圆根区，额前和四周留短发 |
| 马蹄形秃顶 | 顶部及前上方裸露，只保留侧面与后脑发带 |
| 侧梳遮盖 | 同类裸露根区，一侧保留跨顶长束，可剪断或重新梳开 |
| 全秃 | 保留头模与头皮，发体/发束均为零，工具不会产生虚假剪切 |

`HairGrowthMask.ts` 在头部局部空间定义生长区域，`FiberLayout` 在合并发束之前筛掉不生长的根区，避免跨过秃区生成遮盖网格。完整头皮拓扑仍保留供绑定和查看；没有被活动发束引用的导向长度初始化为零，防止剃光工具处理不存在的头发。覆盖发仍由真实侧边根区生成，不是贴上去的发帽。

当前边界按原有根区粒度取样，会有分块；未新增连续密度图、渐疏绒毛、自动生发或永久存档。根区判断沿用本项目头模的尺寸约定，任意比例新头模需先标准化或配置参数。

双头型十五款切换、初始绑定、多角度可剪、封口、全剃恢复通过；新增两项空根区和全秃无副作用检查。完整测试 152 项中 151 通过，唯一失败仍为已有 physics 配置审计；类型检查通过。独立浏览器查看五款正面、圆秃俯视和马蹄后面。未做 Creator 或微信真机验收。
