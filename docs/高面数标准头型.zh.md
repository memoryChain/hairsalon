# 高面数标准头型


日期：2026-09-19。默认标准头型已从椭球占位改为有面部结构的卡通头模。

## 结构和面数

头模主体 12096 个三角面，双耳各 1216 面，总计 14528 面、7270 个索引顶点。面数不包含头发，也不靠眼睛等运行时附件凑满一万面。头部和双耳分别闭合，耳根从头部真实表面射线测量后向内嵌入 0.035 世界单位；不用分离悬浮的小球冒充连接。

造型维持原头皮发际线和头顶尺寸，重点重塑发际线以下的面部：收窄下颌、前置并钝化下巴、塑造眼窝/眉弓、连续鼻梁/鼻尖/鼻翼、口周体积。主要设计比例为头宽约 1.14、头高约 1.39、双耳含外轮廓宽约 1.38；眼距约 0.42，眼线高度 1.74，鼻尖高度 1.52，下颌约 1.0。这里是卡通造型参数，不是写实人体测量规范。

鼻子属于头部连续网格；耳廓有凹陷内面。标准头型的眼睛、眉毛和嘴仍由运行时合批生成，已调整大小和分段，移除旧球状鼻子与耳朵。其他头型沿用原有占位五官。

使用 Blender 法线导出并计算平滑顶点色，避免增加三角形后仍显示大片平面色块。头皮区域保留原表面和顶点对应关系，使用连续法线过渡；没有以增加头发导向数量换取显示头模的平滑。

## 头皮与运行时

原标准头皮保留 321 顶点、608 三角面；发缕仍 304 条，物理导向不增加。所有发根与输入头模顶点的对应索引继续成立；测试要求坐标逐值相同。剪发 BVH 改为使用新的完整头模，所以鼻子和耳朵也参与遮挡。

头部静态几何缓冲统一为 64000 个角点，标准/非标准头型可反复切换，不会因为最初选择低面数模型而容量不足。头部仍合并一次绘制，三维总共仍为头部、围布底座、头发碎发三个绘制网格。顶点法线处理只发生在创建或切换头模时。

## 源文件与重建

- `sceneresource/StandardDetailedHead.blend`：详细头模和对应头皮，包含平滑法线；不含临时验收相机。
- `sceneresource/TestScalps.blend`：保留的基础头型与根域来源。
- `scripts/build-detailed-head.py`：从基础源文件读取标准头模，按每边三等分创建共享顶点，重塑面部、生成并定位耳廓、验证后导出。
- `assets/resources/scalp/test-heads.json`：运行时网格，原资源路径和 meta 保持。
- `sceneresource/detailed-head-audit.json`：主体/耳朵面数、闭合和根部贴合报告。

通过 `scripts/run-blender.py` 运行详细头模脚本即可重建。原 `build-test-scalps.py` 已在流程末尾调用详细头模生成器，因此完整重建不会又变回旧标准椭球。Blender MCP 本次连接不可用，采用独立后台进程；未操作用户的 Blender 窗口场景。

## 验证

Blender 检查正、后、左、右、顶、底及四分之三视角，修正初版过尖下巴和下颌轮廓。自动测试检查真实主体超过一万面、三部分各自闭合/绕序一致、无退化三角形、单位平滑法线、发根坐标不变、真实鼻部深度及头型切换缓冲。

全套测试 64 项：63 通过，仍有 1 项既有 physics 引擎裁剪配置检查失败。TypeScript 检查通过。独立浏览器检查两种发型适配、侧面形状、旋转和投影剪发。未启动或截图 Creator，尚未构建微信包及做 iOS/Android 真机性能验收。

高面数增加了头部 GPU 顶点与 BVH 初始化开销；头发模拟数量不变，不代表所有运行成本不变。模型仍为无贴图的卡通测试资产，不是最终角色美术。
