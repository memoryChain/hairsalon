# 短发初始发根覆盖修复

短碎发侧面露肤可复现。原先只在中心曲线起点沿平均法线出发，整片弯曲根域仍当作刚性截面旋转；短发根域宽度相对于长度更大，转向与收尖后发体可能压进头模。原碰撞修正仅在梳理后执行，初始造型没有同样检查。

现在各发根点先沿自己的头皮法线向外生长，再以平滑过渡接入原发束曲线；短束延后转向和收尖，保留较长的近根部覆盖段。初始短束（原曲线弧长小于 0.5 个场景单位）执行真实头模包络避让；发梢整圈平移保留收尖形状。初始避让结果保存在角色局部坐标，长度不变时只随角色整体旋转复用，不逐帧重新求解；梳理后的动态避让沿用已有逻辑。未梳理的短束惯性摆幅按实际曲线长度的 10% 限制，防止莫西干极短侧发使用长主束的摆幅，在转身时露出皮肤。

没有增加发缕或网格数量，没有添加独立覆盖帽。根域仍逐面归属，根圈仍绑定原始头皮；局部剃除、全剃和剪切继续控制这些真实发体。秃顶款本来不生发的区域不参与覆盖检测。

新增三种头型 × 八类短发相关造型的实际发体射线覆盖检查：对每个应生发根面的四个内部点验证先命中头发再命中头皮。另对四款短发验证急转和八个观察方向的实际遮挡，并验证初始避让缓存、当前与上一帧旋转、全剃不残留。已有收尖、闭合、多刀、梳理与碰撞测试继续运行。浏览器检查短碎发和莫西干的侧面；不把这些检查视为任意头型、任意极短切口及极端梳理均无穿插的证明。
