# 梳理与吹风后的头模避让

2026-09-19，单人离线原型。

## 问题与处理

此前只对曲线控制点做固定椭球外推。控制点在头外不代表曲线中段、宽发束边缘和侧面也在头外，惯性与风位移又可能将其推回头内。

新增 GroomCollision：换头时用实际头模 BVH 从外向内采样 96×49 径向表格，形成跟随头型的保守包络。耳部等径向有多个交点的区域使用最外侧交点。运行时查询表格，不逐发束扫描一万多个头模三角面。

梳理或吹风定型过的发束，在原曲线、截面旋转、惯性和风位移求值之后，检查活动截面顶点、截面边、纵向边、侧面实际对角线和侧面中心，最多四轮将穿入部分移到头外，附加 0.012 单位间距。未碰撞提前结束迭代。原根圈严格保持绑定；当前与上一帧分别使用对应的转动和俯仰姿态。剪切继续使用同一组修正采样及插值绑定，没有重新生成剪掉的部分。

只对已修改造型的发束启用，初始款式保持原样；恢复发型清除启用状态。没有新增发束节点、刚体、材质或三角面。表格和复用工作缓存合计约 49 KiB/头型实例，换头时替换。桌面 Node 单次测量：标准波波头全部 107 束开启保护时，100 次求值平均约 4.0ms（含原发束求值，非微信真机帧耗时）。实际只梳一部分时检查范围更小，但拾取、当前/上一帧重复求值和移动设备成本仍需真机剖析。

## 验证

新增双头型×长发/波波头/尖刺共六项专项测试：反复横向梳理后，使用原始头模射线独立检查活动顶点与三角面中心；检查转动和俯仰后的当前/上一姿态、根部精确绑定、全剃有限值、恢复初始款式。六项通过。原发根可能位于耳部径向包络内，但不能因为外耳遮挡而移动根绑定；测试把原根固定性和活动发体穿透分开检查。

完整 119 项中 118 通过，唯一失败仍为已有 physics 模块配置审计。类型检查通过，字体生成/审计通过：61 文件、644 字符，Regular 216.3 KiB / SemiBold 216.2 KiB。独立浏览器用第七款向头内侧梳理，并旋转至 31°、俯仰 11°检查轮廓，修剪保持为零。未启动或截图 Creator、未构建微信包或真机验收。

## 边界

这是离散发体的防穿透优化，不是精确连续碰撞或束间碰撞。原根圈不移动；有限采样间、非常凹的未来头型、极端切口及发束互相穿插仍可能残留问题。保护会局部推出活动几何，显示轮廓可稍微膨起，曲线弧长约束仍保留但显示面不承诺严格不可伸长。任意新头型需确认中心与外包络适用性，并重新验证。
