# 十款发际线整理

2026-09-19。调整实际发根覆盖边界，并分别修正刘海轮廓。

## 造型调整

| 款式 | 调整 |
| --- | --- |
| 赛亚尖刺 | 保留较低的额中与轻微额角变化，修正额头到耳边的大斜坡 |
| 齐刘海长发 | 扩宽刘海到两侧额角，发尾略抬高、保持小幅弧度 |
| 清爽短碎发 | 额角收整、短鬓角、后颈略抬高 |
| 莫西干 | 较高而利落的额线，两侧发束缩短贴头，保留中间长脊 |
| 蓬松背头 | 额角略退、露额边界清晰，保留向后梳的主体 |
| 侧分短发 | 整理额角和耳前收口，保留两侧分流 |
| 齐刘海波波头 | 齐刘海发尾抬高并收缓弧度，修整耳前边缘 |
| 及肩中发 | 去掉中间孤立的小撮刘海，改为连续的中分开额轮廓 |
| 不对称短发 | 保留偏分斜刘海，缩小高低差，消除垂到鼻梁的中间尖束 |
| 外翘短发 | 扩宽并抬高齐刘海，两侧外翘保持 |

所有款式都重新整理额中、额角、耳前短鬓、耳上轮廓、耳后与后颈的过渡，按各款设置不同边界。发际线是发根边界，刘海是发梢轮廓，两者分别控制。

## 实现与范围

HairlineProfile 在切换头型/首次切换款式时，把原根域按方位映射到各款边界，再投影到实际头模三角面。每个新发根记录三角面及重心权重，ScalpTopology 校验其位置确实在绑定面上。没有改写 Blender 源模型或测试头模 JSON，没有增加覆盖发帽，也没有改变原头皮顶点数、三角索引或根域连通关系。头皮标准 608 面、非标准 756 面保持不变；发束分区可能随曲面边长和方向少量变化，例如标准波波头目前 105 束 / 9396 面。

同一头型的各款拓扑按需缓存，恢复不会在已变形结果上继续映射，普通工具切换不重建。该方位映射针对目前两种围绕头部中心连续覆盖的测试头皮；未来有严重凹陷、非径向边界或任意拓扑的头皮需要对应的适配验证，不宣称通用自动美术。

HeadRaycast 增加局部表面交点与法线读取，共边射线使用小浮点容差。短发轮廓调整暴露出已有平面封口仅根据平面法线决定绕序的问题，改为对照保留侧边界确定封口方向；原闭合与相反边绕序断言保留。

## 验证

独立浏览器逐款检查标准头型正面，短碎发检查侧面 88°、背面 177°和非标准头型。原剪剃、梳理、吹风保型、跨侧覆盖与防穿透测试通过。未启动或截图 Creator，未构建微信包或做微信真机验收。
