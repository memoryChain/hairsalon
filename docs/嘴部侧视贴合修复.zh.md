# 嘴部侧视贴合修复

2026-09-20：理发主场景的嘴部来自 FaceGeometry 独立五官网格。此前向外偏移 0.012–0.022，且椭圆使用大三角扇，侧视能看到脱离脸部的贴片。

改为优先对实际可见 characterMesh 采样，深度缓存从 64 格提高到 128 格；嘴部三角形最长边限制为五官设计坐标的 4 像素，逐点沿脸部深度贴合。嘴部层偏移缩小为 0.0012–0.0017，保留唇边与口腔的层次。表面射线采样只在切换模型时发生，表情更新复用原有固定容量缓冲；没有修改源模型或贴图。表情对比页原本直接在角色材质上绘制嘴巴，不存在独立嘴部贴片，无需修改。

新增测试对用户模型和两个内部测试模型的五种情绪进行嘴部顶点、面内采样，要求相对可见脸面间距大于 0 且小于 0.0035，并检查缓冲复用。独立浏览器验证正面及 90 度、98 度侧面。类型检查、字体检查通过；223 项测试通过 222 项，唯一失败仍为原有 physics 模块配置断言。未进行 Creator 或微信真机验收。
